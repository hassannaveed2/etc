Types of tests we deliver

From machine-scored MCQs to rubric-marked essays, skill tasks and psychological assessment.

MCQ-based tests
Objective questions with one correct answer, scored by machine quickly and without bias.
Descriptive tests
Written answers or essays scored against a fixed rubric by trained examiners.
Skill tests
Practical tasks that check whether a candidate can actually perform defined skills.
Physical tests
Measured physical tasks against defined standards, for example police recruitment.
Psychological assessment
Standardized tools that measure personality, aptitude or behavioural traits for selection and placement.
